# でんし黒板

PDFやWord（.docx）、JPEG・PNGを読み込んで、大型モニターで表示しながら書き込めるブラウザーアプリです。

## 起動方法

`index.html`をWebサーバーで配信し、ブラウザーで開いてください。PDF・Wordの表示とPDF出力にはCDNからライブラリーを読み込むため、初回起動時および各形式の利用時にインターネット接続が必要です。

## 使い方

1. 資料一覧からPDF、Word（.docx）または画像を選択するか、ドロップします。旧形式のWord（.doc）には対応していません。
2. 画面右側に固定されたペン・マーカー・消しゴム、取り消し、拡大縮小を使って編集します。選択中のペンまたはマーカーをもう一度押すと閲覧モードになり、ドラッグでスクロール、2本指のピンチで拡大・縮小できます。色は16色から選べます。複数ページのPDF・Wordはページ移動できます。
3. 書き込み、ページ、表示倍率はブラウザー内に自動保存されます。資料一覧から名前変更・削除・再開ができます。
4. 「全画面」ボタンでブラウザーのアドレスバーなどを隠して表示できます。表示中のページをJPEGで、資料全体をPDFで出力できます。

保存データは同じブラウザー内に保持されます。ブラウザーのデータを消去した場合や、別の端末・ブラウザーでは利用できません。
